# Roobert font files

Place licensed WOFF2 files in this folder using these exact names:

- `Roobert-Regular.woff2`
- `Roobert-Medium.woff2`
- `Roobert-SemiBold.woff2`
- `Roobert-Bold.woff2`

The editor automatically falls back to Inter and Arial when these files are not present. Roobert is not distributed with this project.
